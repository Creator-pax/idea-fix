## 1. Описание бота

**MAX Школьный помощник** — это бот для мессенджера MAX, который помогает школьникам с учёбой.

### Возможности:

| Функция | Описание |
|---------|----------|
| 🤖 ИИ | Ответы на вопросы, расписание, тесты, помощь с домашкой |
| 📝 Заметки | Создание, просмотр и удаление заметок |
| 📂 Файлы и медиа | OCR фото, текст из PDF, распознавание речи и ключевые моменты видео |
| 🖥 Интерфейс | Настройка эмодзи, компактного режима и счётчиков |
| 🛡 Модерация | Подтверждение новых пользователей, блокировки, рассылки |
| ⚙️ Настройки | Настройка стиля ИИ, лимитов, тем, интерфейса |

### Зачем так?

|------|-----------|
| `config.py` | Хранит токены и настройки. Меняешь в одном месте |

## 6. Регистрация пользователей

### Процесс регистрации

1. Пользователь пишет `/start`
2. Бот показывает выбор роли: [Ученик] [Учитель]
3. Пошаговый ввод данных:
   - **Ученик**: телефон → пароль → имя → класс → школа
   - **Учитель**: телефон → пароль → имя → школа
4. Заявка отправляется на модерацию
5. Модератор подтверждает/отклоняет

### handlers/registration.py

```python
@bot.command("start")
def cmd_start(ctx):
    user_id = ctx.user["user_id"]
    
    if db.user_exists(user_id):
        # Уже зарегистрирован — показываем меню
        show_main_menu(ctx, user_id)
    else:
        # Новый пользователь — начинаем регистрацию
        ctx.reply("Кто ты?", keyboard=ROLE_KEYBOARD)
```

### handlers/start.py

```python
@bot.command("help")
def cmd_help(ctx):
    ctx.reply("Справка по командам...")

@bot.command("menu")
def cmd_menu(ctx):
    show_main_menu(ctx, user_id)
```

## 11. Настройки интерфейса

Каждый пользователь может настроить внешний вид бота под себя
в разделе «Настройки → Интерфейс».

| Настройка | Значения | Что делает |
|-----------|----------|------------|
| Эмодзи | Вкл / Выкл | Показывает или скрывает эмодзи в меню, профиле и настройках |
| Компактный режим | Вкл / Выкл | Укорачивает приветствие в главном меню (без роли и чисел) |
| Счётчики в меню | Вкл / Выкл | Показывает/скрывает «ИИ: X/Y» и «Заметок: N» в главном меню |

### handlers/prefs.py

Настройки хранятся в таблице `users` (колонки `show_emoji`,
`compact_mode`, `show_stats`) и читаются через `get_ui_prefs()`.

```python
from handlers.prefs import get_ui_prefs, set_ui_pref

prefs = get_ui_prefs(user_id)
print(prefs["show_emoji"], prefs["compact_mode"], prefs["show_stats"])

set_ui_pref(user_id, "compact_mode", True)
```

Значения по умолчанию для новых пользователей задаются в `config.py`:

```python
UI_SHOW_EMOJI = True      # эмодзи включены
UI_COMPACT_MODE = False   # обычное (не компактное) меню
UI_SHOW_STATS = True      # счётчики видны
```

## 13. Файлы и медиа

Раздел помогает работать с учебными файлами: распознать текст с фото или из PDF, вытащить речь из видео и найти ключевые моменты. Вход — кнопка «📄 Файлы и медиа» в главном меню.

### Меню раздела

```
📂 Файлы и медиа

Я могу помочь с учебными файлами:
• Фото с текстом → распознаю текст (OCR)
• PDF → вытащу текст из документа
• Видео → распознаю речь или найду ключевые моменты

[📸 Текст с фото]
[📄 Текст из PDF]
[🎤 Распознать речь]
[🎞 Ключевые моменты]
[← Назад в меню]
```

### Возможности

| Действие | Что делает |
|----------|------------|
| 📸 Текст с фото | OCR фото через `easyocr` (русский + английский), возвращает распознанный текст |
| 📄 Текст из PDF | Извлекает текст со всех страниц через `PyPDF2` |
| 🎤 Распознать речь | Достаёт аудио из видео (`moviepy`), переводит в текст через `speech_recognition` (Google, ru-RU) |
| 🎞 Ключевые моменты | Ищет смену сцен в видео и присылает до 5 миниатюр-кадров |

### ИИ-постобработка

После распознавания текста под сообщением появляются кнопки:

| Кнопка | Действие |
|--------|----------|
| ✏️ Исправить ошибки | ИИ исправляет ошибки распознавания OCR |
| 📚 Решить задание | ИИ решает/объясняет задание из текста |
| ✅ Готово | Завершить обработку |

ИИ-постобработка использует общий лимит запросов ИИ (`db.check_ai_limit`), пишет результат в логи (`db.save_ai_log`) и fallback'ит: если ответ длинный — отправляет его файлом.

### Обработка (handlers/media.py)

- `handle_media_menu` — кнопки раздела и переход в режим ожидания файла (FSM `MediaStates`).
- `handle_media_attachments` — приём фото / PDF / видео, разбор по состоянию.
- `_process_photo`, `_process_pdf`, `_process_video` — основная работа.
- Ошибки чтения (нет текста, `UnknownValueError`, `RequestError`) возвращают понятное сообщение.

> ✅ Чтобы раздел заработал, установи медиа-зависимости (`pip install -r requirements.txt`). Без них обработчики корректно просят «установить библиотеки» вместо падения.

from state_manager import set_state, get_state, clear_state
